# CityScanPCG

[English](README.md) | **简体中文**

CityScanPCG 是一个使用 C# 编写的 Unity 程序化城市生成插件。它通过规则生长生成主次路网，从道路几何关系推导街区和建筑地块，构造挤出式建筑网格，并支持在道路和公园周边放置可配置的道具。

## 项目功能

- **道路网络：** 主路按规则概率分支并改变走向，支路按前方及左右方向正交生长。候选路段会进行端点吸附、线段相交检测和方向约束，路口节点度数最多为 4。
- **街区与地块：** 根据道路宽度计算街区边界，并通过轮廓内缩预留人行道；随后用随机切线递归划分地块，并按外接矩形面积和长宽比筛选。
- **程序化网格：** 凸多边形使用扇形剖分，凹多边形使用耳切法；生成顶面、侧面、渲染器和碰撞体。边界顶点超过 10 个的街区可标记为公园。
- **可选道具：** 独立组件按道路和公园位置采样，放置已配置的车辆、道路道具和长椅预制件。
- **调试：** 支持 Inspector 参数、Gizmos，以及道路、地块和后台城市计算三类阶段耗时日志。

## 技术栈

- Unity 2023.2（核查工程版本为 2023.2.20f1c1）
- C#、UnityEngine
- 图结构与计算几何
- 程序化 Mesh、System.Random、后台 Thread 和 Unity 协程

## 生成流程

````mermaid
flowchart LR
    A[随机种子与参数] --> B[主路生长]
    B --> C[支路生长与清理]
    C --> D[道路图]
    D --> E[偏移生成街区边界]
    E --> F[递归切分建筑地块]
    F --> G[多边形三角剖分]
    G --> H[主线程创建 Unity 对象]
    H --> I[可选生成道路与公园道具]
````

路网算法受扩展 L-system 思路启发；源码实现的是明确的道路生长规则，并非通用文法解析器。地块切线从外接矩形边上的 30%、40%、50% 或 60% 位置选取；递归最多切分 6 轮。当候选地块的**外接矩形**面积小于 10 Unity 单位²，或长宽比大于 4 时，拒绝该次切分。这些数字描述算法规则，不代表测得的质量或性能结果。

## 快速开始

1. 打开 Unity 2023.2 项目。
2. 将 Assets/CityScanPCG 复制到项目的 Assets 目录，等待 Unity 导入脚本和材质。
3. 新建空 GameObject，并添加 CityGenerator 组件。
4. 进入 Play 模式；道路、街区和地块对象会在运行时生成。
5. 如需放置道具，添加 RandomObjectSpawner 组件，指定 CityGenerator，并在 Inspector 中为车辆、道路道具数组和长椅字段配置非空预制件。

如果在已有工程中替换原来的 CityPCG 文件夹，请先移除旧副本再添加本仓库；此源码发行版保留了 Unity 资源 GUID。

道具组件需要由使用方提供预制件。本仓库没有包含原开发工程中的第三方模型资源包。

## 主要参数

| 参数 | 核查场景中的默认值 | 含义 |
|---|---:|---|
| mapSize | 300 | 道路平面在水平两轴上从 -mapSize 延伸到 +mapSize；扰动前为 600 × 600 Unity 单位。 |
| seed | 13 | 城市生成随机种子。 |
| maxMajorRoad | 2,000 | 主路段生成上限；应用 ±10% 参数随机扰动之前的配置值。 |
| maxMinorRoad | 10,000 | 支路段生成上限；应用 ±10% 参数随机扰动之前的配置值。 |
| branchingProbability | 0.075 | 主路分支控制参数，实际受配置区间限制。 |
| crossingDeletionProbability | 0.1 | 控制支路清理过程中部分节点的删除概率。 |
| majorThickness / minorThickness | 2.5 / 0.9 | 生成街区边界时使用的道路宽度。 |
| sidewalkThickness | 0.5 | 生成建筑地块时使用的内缩距离。 |
| minBuildHeight / maxBuildHeight | 2 / 45 | 建筑高度生成的输入参数；当前实现不能保证最终高度都严格处于该范围内。 |

启动时，城市生成参数中有 11 项会进行约 ±10% 的随机扰动，部分参数还会受上下限约束。道具生成使用单独的 randomSeed（核查场景中为 42）。固定种子可控制随机源，但完整场景的一致性尚未经过验证。

## 性能与验证状态

源码记录道路生成、地块生成和后台城市计算三类耗时。城市耗时计时在主线程创建 Unity GameObject、网格、渲染器和碰撞体之前结束。本仓库未包含可引用的性能日志、帧率结果、内存数据或 CityScanPCG 自动化测试结果。

当前对象在主线程逐个创建；本版本没有实现 GPU Instancing、对象池、网格合并、LOD 或 Unity Jobs/Burst。生成速度、帧率、内存、生成数量、道具位置质量和完整场景复现率均应在明确的 Unity Player 构建版本与硬件上测量后再报告。
